# 🍽️Restaurant Review App
Welcome to the Restaurant Review App! This is your go-to place for discovering great dining spots, reading reviews, and sharing your own positive experiences!
This magnificent app makes it easy to explore and connect with the local food scene based in Debrecen, let's dive in and discover your next favorite meal and restaurant!

## 💻Features
- 🔎Restaurant Search: Search for restaurants by name, cuisine or description.
- 🙋User Reviews: Read reviews and ratings from other users, or share your own.
- 💖Favorites: Save your favorite restaurants for easy access in the future.
- 📌Map View: See restaurants plotted on a map for easier discovery.

## 🚀 Getting Started
Follow these instructions to set up and run the app locally for development or testing.

### 📒Prerequisites

Ensure you have the following installed:
- [Java 23](https://www.oracle.com/java/technologies/downloads/)
- Spring Boot 3.3.4
- Maven latest

### 🏃Build and Run the App:
```sh
mvn clean install
mvn spring-boot:run
```
### 🔧Access the deployed app
- https://restaurant-review-app-szfm-production.up.railway.app/

### 🔧Access the app locally
- http://localhost:9090/

## 📝 Technologies Used
- **Backend**: Spring Boot, Java
- **Frontend**: React
- **Database**: H2 
- **Authentication**: JWT
- **Mapping**: OpenStreetMap
