# Guided Report

Reports gathered from product owner for requirements
---

- Do you only need a map to be present? **They should be able to view the restaurants in a list instead of only on a map**

- It is easier to just show a pin instead of a dot, would that be an issue? **No**

- Should the list view and map view have the same view for the restaurants? **Yes, they can be reused**

- Should the users be able to search these restaurants? **Yes, they should have the ability to filter their search by the restaurant name and type**

- Should the users need an account to add reviews? **No need for account management**

- What should the review system be? **5 starts**

- What should the minimum amount the users can give? **1 star**

- What increments? Can they give half stars? **No half stars, use whole star increments**

- What types of restaurants should restaurants have?
    - 🍔 **Fast Food**
    - 🥗 **Healthy**
    - 🍟 **American**
    - 🥡 **Chinese**
    - ☕ **Café**
    - 🍜 **Japanese**
    - 🍴 **Fine Dining**
    - 🍨 **Dessert**
